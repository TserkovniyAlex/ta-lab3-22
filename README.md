# Лабораторна робота № 3 — Сортування купою (HeapSort)

## Варіант 22

Вхідна послідовність: `19, 75, 43, 31, 5, 66, 62, 34, 76` (n = 9)

Результат сортування: `5, 19, 31, 34, 43, 62, 66, 75, 76`

## Запуск

Потрібен Python 3.8 або новіший, сторонні бібліотеки не потрібні.

```bash
python heapsort.py
python heapsort_trace.py
python stability_check.py
python quicksort.py
```

## Результати

Підрахунок виконано за методикою ЛР1: враховуються порівняння значень елементів та присвоювання, передбачені обраною методикою підрахунку (обмін = 3 присвоювання, а також службові присвоювання змінним, що керують ходом алгоритму).

| Алгоритм | Порівняння | Присвоювання |
|---|---|---|
| HeapSort | 34 | 141 |
| QuickSort | 19 | 61 |

## Висновки

- HeapSort має часову складність O(n log n) у найкращому, середньому та найгіршому випадках і сортує на місці (O(1) додаткової пам'яті).
- HeapSort — **нестійке** сортування: на масиві `[3₁, 3₂, 1]` порядок однакових елементів змінюється (`[1, 3₂, 3₁]`), див. `stability_check.py`.
- QuickSort у середньому має складність O(n log n), але в найгіршому випадку — O(n²).
